# HASHOUT log

## v0.1.0

- Why this capability: FormTray's Widgets board shows app tiles, groups and the updates tile only. Nothing in its code, docs, CLI or command catalogue times work sessions, and a board that sits beside every Form app is where a focus timer belongs.
- One `dock` panel, `main`, so it opens as a Widgets tile. FormTray mounts dock panels as tiles of size s, m or l (about 111 x 80, 258 x 54 and 258 x 170 px of frame at the 920 px panel). The page has one layout per size chosen by media queries on the frame's own size, never by script: under 140 px high it is one row (ring, phase, Start and Skip), under 200 px wide it is the ring alone with the time, and the large tile has the note, the four controls and the seven-day chart. A taller frame (over 240 by 300) gets a bigger ring.
- No permissions. `storage.*`, `ui.notify` and `ui.setTitle` need none, so FormTray shows no consent card and the tile starts at once. The board itself (`document.*`) is not needed by a timer.
- State lives in `storage` under one key, `state`: settings, the running session and the log. The session stores `resumed` (the clock time of the last start or resume) and `spent` (ms run before that), never a countdown, so a tile that is reloaded, moved, resized or remounted after FormTray restarts works out where it is from the clock. A session that ended while no frame was alive is logged at its true end time, and the toast says "Your focus session ended at 10:25." instead of the live wording; the chime plays only when the end is under 15 s ago. With auto-start on, up to 64 missed sessions are chained from their true end times.
- Log entries are `{ s, e, m, k, ok, n }`: start and end time, focused ms (pauses excluded), `f` or `b`, whether it ran to the end, and the note. A focus session stopped by Reset or Skip after a minute or more is logged with `ok: false` ("Stopped at 12 min") and counts toward the day's minutes but not its sessions. Under a minute is not logged. Entries older than 60 days, or past 1500 entries (about 180 KB with 45-character notes, under the contract's 256 KB), are trimmed on each save. If the host refuses a save for size, the log is trimmed to 14 days and saved again, and the tile says so.
- Day sums use the local day the session started on. The chart is the last seven days ending today, scaled to the larger of the daily goal and the best day; the dashed line is the goal. A bar opens that day's sessions in a sheet inside the tile; a 30 s check redraws the chart when the day changes.
- The chime is synthesised with Web Audio (three sine partials per bell, two bells, rising for the end of a break and falling for the end of a focus). FormTray's frame is sandboxed with `allow=""`, so audio starts only after a pointer press inside the frame; the page primes its AudioContext on the first press. A session started from the Extensions menu or the CLI with no press in the tile may end silently; the toast still shows.
- `ui.setTitle` is sent only when its text changes (once a minute while running): FormTray prefixes the extension name, so the tile title reads "Focus Timer: Focus, 24 min left".
- Commands all name the panel, so FormTray docks the tile if needed, shows Widgets and activates it: `toggle` (start, pause or resume), `skip`, `today` (opens today's sheet). Each answers `{ phase, status, left_seconds, today_minutes }`, which is what `formtray-cli extension_command focus-timer toggle` prints.
- Tokens: the page's `:root` repeats FormTray's dark and light values for the contract tokens (`--bg` from `--ground`, `--panel` from `--pane`, `--text` from `--ink`, `--muted` from `--ink-soft`, `--accent` from `--focus`, `--border` from `--edge-strong`, `--radius`, `--font`) under the same `prefers-color-scheme` test FormTray uses, so the first paint already matches and `host.hello` changes nothing visible. Everything else is mixed from those tokens. The progress ring's transition is off until two frames after the first fill, so a restored session does not sweep.
