## Formats

WebVTT is a W3C format; the `#xywh=` media fragment is from the W3C Media Fragments URI specification. The ZIP writer follows the public PKWARE APPNOTE (stored entries only). All code is written for this extension.

The package carries no media, fonts or models. The README screenshot shows frames of Pexels footage, credited in `CREDITS.md`.
